# Changelog

## [0.2.0] - 2026-08-29

### Added

- Unit definitions have been moved to more easily editable configuration files
- Pure python section has been added for easy unit and constant imports
- Custom unit support with `Firkin.custom()`

## [0.1.0] - 2026-08-27

_Initial release._

Includes the following features:

- Unit-attached numbers for scientific and engineering calculations
- Includes all SI units as well as many common metric and US customary units
- Arbitrary prefix implementation
- Many physical constants
- Python string and number coercion
- Common non-arithmetic number operations such as round, exp, log, and log10
